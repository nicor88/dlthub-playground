This guide will help you set up and run the dltHub playground project for data ingestion and processing.

Prerequisites

  • Python 3.12 or higher
  • uv package manager (follow installation instructions)
  • Databricks account with access to create schemas and volumes

Initial Setup

1. Install uv

If not already installed:

curl -LsSf https://astral.sh/uv/install.sh | sh

2. Initialize the project

make init

3. Set up environment variables

Create a .env file in the project root with the following variables:

# Databricks credentials
DESTINATION__DATABRICKS__CREDENTIALS__HOST=your-databricks-host
DESTINATION__DATABRICKS__CREDENTIALS__HTTP_PATH=your-http-path
DESTINATION__DATABRICKS__CREDENTIALS__ACCESS_TOKEN=your-access-token

# Source API tokens (example for Jira)
JIRA_API_TOKEN=your-jira-api-token
JIRA_EMAIL=your-email@example.com
JIRA_SUBDOMAIN=your-subdomain

Databricks Setup

1. Generate Access Token

  • Go to Databricks Settings (top right) → Developer → Access Token
  • Generate a new Personal Access Token (PAT)

2. Create Target Schema

CREATE SCHEMA IF NOT EXISTS your_catalog.dlt_playground_nico;

3. Create Volume

CREATE VOLUME IF NOT EXISTS your_catalog.dlt_playground_nico.dlt_volume;

Available Sources

Jira Source

To set up the Jira source:

1. Initialize Jira source

dlt init jira duckdb

2. Copy to sources directory

The generated jira folder should be copied to the sources directory.

3. Configure Jira credentials

Add to your .env file:

JIRA_API_TOKEN=your-jira-api-token
JIRA_EMAIL=your-email@example.com
JIRA_SUBDOMAIN=your-subdomain

Running Pipelines

The project includes several example pipelines in the pipelines/databricks/ directory:

  • jira_ingestion.py - Jira data ingestion
  • python_source_ingestion.py - Python source data
  • rest_github_ingestion.py - GitHub REST API ingestion
  • rest_jira_ingestion.py - Jira REST API ingestion
  • rest_pokemon_ingestion.py - Pokemon API ingestion

To run a pipeline:

python pipelines/databricks/your_pipeline.py

Environment Variables

This project uses environment variables for configuration:

  • Destination secrets: Prefixed with DESTINATION__DATABRICKS__CREDENTIALS__
  • Source secrets: Prefixed with the source name (e.g., JIRA_API_TOKEN)

The project uses python-dotenv to automatically load variables from the .env file.

Development

Code Quality

The project uses:

  • ruff for linting and formatting
  • isort for import sorting
  • pre-commit for git hooks

Run linting:

uv run ruff check .
uv run ruff format .

Troubleshooting

Common Issues

  • Missing environment variables: Ensure all required variables are set in your .env file
  • Databricks connection issues: Verify your access token and host configuration
  • Source API errors: Check your API tokens and rate limits

Getting Help

  • Check the dltHub documentation
  • Review the example pipelines in pipelines/databricks/
  • Ensure all dependencies are installed with uv sync
